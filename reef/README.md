# 记忆礁（原型）

潜水扫描 + 卡牌游戏的玩法原型。暂时放在潜学仓库里，之后可以搬到独立仓库。

试玩：`reef/index.html`，顶部切换两种玩法：

- **牌局**：三条水道（蓝水、礁石、沙地）的拉锯。手里是牌，打出去变成在海里游的生物。每回合结束每条道比大小：净化力 ≥ 污染值，污染退一格；不够，污染进一格并盖住那格的生物。紧挨污染的一格净化力 ×2。三条道都推干净过关，任何一条道被占满失败。`cgsim.js`、`mc.js` 用简单策略和推演攻击规则。
- **守礁**：水道防守。藻团和长棘海星从外海漂来，把鱼放进水道挡住它们。5 关。

源码在 `src/`：`cg.js`（牌局规则和卡牌）、`cgsim.js`（牌局模拟）、`td.js`（守礁规则和关卡）、`tdsim.js`（守礁模拟）、`index.src.html`（界面）、`art.js`（插画）、`build.py`（合成单个 HTML）。
`cgui.js` 是牌局界面。`src/old/`、`src/old2/`、`src/old3/` 是更早的几版。
