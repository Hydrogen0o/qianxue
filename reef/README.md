# 记忆礁（原型）

潜水扫描 + 卡牌净化游戏的牌局原型。暂时放在潜学仓库里，之后可以搬到独立仓库。

试玩：`reef/index.html`，顶部可切换两版：

- **v1 摆鱼**：把鱼放进礁盘上对应的家，相邻关系和种类数决定得分。8 关，每关加一条规则。
- **v2 组牌**：从手牌里选一组牌放流，按牌型（同一个家、鱼群、食物链、搭档）算倍数。8 关，每关加一个牌型或规则。

源码在 `src/`：`core.js`（两版的规则和关卡）、`index.src.html`（界面）、`art.js`（插画）、`tune.js`（穷举和模拟，用来定每关目标分）、`build.py`（合成单个 HTML）。`src/old/` 是最早那版复杂规则。
